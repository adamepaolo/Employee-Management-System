Employee Management

Comprehensive Employee Record Management

Manage all employee-related information from hiring to retirement in one centralized system.

  1. Navigate to Employee Management > Register Employee
  2. Fill in all required fields (marked with *)
  3. Upload employee photo and documents
  4. Review all information for accuracy
  5. Click "Save" to complete registration

Use the Search Profiles feature to find employees by:

  • Name (full or partial)
  • Employee ID
  • Department/Designation
  • Company
  • Status (Active, Inactive, Retired)

Flight Management

Comprehensive Travel Management System

Track all employee travel arrangements, including flights, transit details, and documentation.

  1. Navigate to Flight Management > New Trip
  2. Select the employee
  3. Enter flight details (PNR, ticket number)
  4. Add departure and arrival information
  5. Specify transit details if applicable
  6. Save the flight record

Document Management

Secure Document Storage and Tracking

Manage all employee documents including visas, passports, and identification.

Supported document types:

Passport Visa Work Permit
  1. Go to the employee's profile
  2. Select the "Documents" tab
  3. Click "Upload New Document"
  4. Select document type and file
  5. Enter expiration date if applicable
  6. Click "Save Document"
