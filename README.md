# Employee Management System 🚀

[![Python](https://img.shields.io/badge/Python-3.x-blue)](https://www.python.org/) [![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

A simple **Employee Management System** built with **Python** and **HTML templates** to manage employee records. Features include **Add, View, Update, Delete** employee data stored in a lightweight **SQLite database** (`Operations.db`).  

**Project Structure:**  
`Employee_Management_System.py` | `templates/` | `static/` | `Operations.db` | `LICENSE`  

**Technologies:** Python, HTML/CSS, SQLite  

**Quick Start:**  
1️⃣ Clone: `git clone https://github.com/adamepaolo/Employee-Management-System.git`  
2️⃣ Install dependencies: `pip install -r requirements.txt`  
3️⃣ Run: `python Employee_Management_System.py`  
4️⃣ Open: `http://localhost:5000`  

**Contribute:** Improve UI/UX, add authentication, implement search/filter, or upgrade database. Pull Requests welcome!
